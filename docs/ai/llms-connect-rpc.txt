# ConnectRPC Integration Guide

For full architectural invariants and design system rails, see [AGENTS.md](../../AGENTS.md).

## Philosophy & Tooling
ConnectRPC is a modern, typed RPC framework developed by Buf. It runs over standard HTTP/1.1 and HTTP/2 with JSON or Protobuf payloads, working natively in browsers without gRPC-web proxies.
- Protobuf Spec: `proto/`
- Buf Tooling: `buf.yaml`, `buf.gen.yaml`
- Code Generation: `bunx @bufbuild/buf generate`

## Schema SSOT & Client Setup
All RPC services and payload contracts originate from `.proto` schemas or `src/schema/connect.ts`.
```typescript
import { createClient } from "@connectrpc/connect";
import { createConnectTransport } from "@connectrpc/connect-web";
import { SystemService } from "~/gen/system/v1/system_pb";

const transport = createConnectTransport({
  baseUrl: "http://localhost:8080",
});

export const systemClient = createClient(SystemService, transport);
```
