# Solid.js 2.0 AI Instructions & API Guide

For full architectural invariants and design system rails, see [AGENTS.md](../../AGENTS.md).

## Core API Patterns

### 1. Async-First Reactivity & Computations
Computations and `createMemo` can return Promises directly. The reactive graph natively handles transitions without tearing:
```tsx
const data = createMemo(async () => {
  const res = await fetch(`/api/user/${id()}`);
  return res.json();
}, { name: "user-data" });
```

### 2. Boundary Replacement
- **Loading fallback**: Replace Solid 1.x `<Suspense>` with `<Loading on={...} fallback={<Spinner />}>`.
- **Error containment**: Replace `<ErrorBoundary>` with `<Errored fallback={(err, reset) => <ErrorView error={err()} onRetry={reset} />}>`.

### 3. Split `createEffect`
Takes two functions: compute (tracks dependencies), then apply (runs side effect without re-tracking):
```tsx
createEffect(
  () => count(),
  (val) => {
    document.title = `Count: ${val}`;
  }
);
```

### 4. Direct Draft Stores
Store updates execute directly against the draft proxy without requiring external `produce`:
```tsx
const [store, setStore] = createStore({ users: [] });
setStore((draft) => {
  draft.users.push({ id: "1", name: "Alex" });
});
```

### 5. Transition Actions & Optimistic State
In transition handlers, acknowledge holds immediately with `createOptimistic` before the first async `yield`:
```tsx
const [isPending, setIsPending] = createOptimistic(false, { name: "save-pending" });
const saveAction = action(function* (data) {
  setIsPending(true);
  const result = yield api.save(data);
  return result;
});
```

### 6. Solid 2.0 Anti-Patterns
- ❌ **Destructuring Props**: `function Button({ label, onClick })` loses reactivity. Always use `props.label`.
- ❌ **Passing Accessors to Primitives**: `<Input value={name} />` is invalid. Pass evaluated signal: `<Input value={name()} />`.
- ❌ **Legacy 1.x APIs**: `createResource`, `createComputed`, `onMount`, `splitProps`, `mergeProps`, and `.Provider` are removed in 2.0.
- ❌ **Web Primitives from `solid-js`**: Import `Dynamic`, `Portal`, and `isServer` from `@solidjs/web`.
