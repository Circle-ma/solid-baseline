# SpacetimeDB Integration Guide

For full architectural invariants and design system rails, see [AGENTS.md](../../AGENTS.md).

## Philosophy & Tooling
SpacetimeDB combines database, application logic, and serverless execution into a single unified engine.
Clients communicate over WebSocket, syncing subscribed tables directly into local in-memory caches.
- CLI: `spacetime`
- MCP Server: `spacetime mcp`

## Schema as Single Source of Truth (SSOT)
- Tables, rows, and reducer payloads must strictly derive from `src/schema/spacetimedb.ts` or generated `src/module_bindings/`.
- Ad-hoc interface or type definitions in routes/lib are forbidden.

## Standard Client & Reactive Workflow
1. **Connection & Subscriptions**:
```typescript
import { DbConnection, tables } from "~/module_bindings";

export const conn = DbConnection.builder()
  .withUri(import.meta.env.VITE_SPACETIMEDB_URI || "ws://localhost:3000")
  .withDatabaseName("my_module")
  .withAutomaticReconnect()
  .onConnect((connection) => {
    connection.subscriptionBuilder()
      .onApplied((ctx) => {
        // Initial bulk load
      })
      .subscribe([tables.my_table]);

    // Incremental real-time row events
    connection.db.my_table.onInsert((_ctx, newRow) => { /* update store */ });
    connection.db.my_table.onDelete((_ctx, oldRow) => { /* update store */ });
  })
  .build();
```

2. **Calling Reducers (Transactions)**:
```typescript
await conn.reducers.myAction({ payload: "data" });
```
