# Panda CSS 2.4 Design System Guide (Paved Path Edition)

For design tokens, stacking context, and global invariants, see [AGENTS.md](../../AGENTS.md).

## Library-Specific API Patterns

### 1. Slot Recipes (`sva`) in `panda.config.ts`
All compound components define their visual anatomy via Panda CSS 2.4 slot recipes:
```ts
import { defineSlotRecipe } from "@pandacss/dev";

export const cardRecipe = defineSlotRecipe({
  className: "card",
  slots: ["root", "header", "title", "description", "body", "footer"],
  base: {
    root: {
      display: "flex",
      flexDirection: "column",
      gap: "6",
      p: "6",
      bg: "bg.canvas",
      borderWidth: "1px",
      borderStyle: "solid",
      borderColor: "border.subtle",
      borderRadius: "l3",
      boxShadow: "sm",
    },
    title: {
      textStyle: "lg",
      fontWeight: "semibold",
      color: "fg.default",
    },
    // ...
  },
});
```

### 2. Systematic Component Anatomy
Expose slot recipe classes via pre-composed UI primitives:
```tsx
import { card } from "styled-system/recipes";

export const CardRoot = (props: CardProps) => {
  const classes = card();
  return <div class={cx(classes.root, props.class)}>{props.children}</div>;
};
```

### 3. Anti-Patterns & Prohibitions
- ❌ **`styled-system/jsx` in feature code**: Panda's JSX factory targets Solid 1.x. Always use `~/components/ui` (`<Container>`, `<VStack>`, `<HStack>`, `<Grid>`, `<Box>`).
- ❌ **Direct `styled-system/css` in feature code**: Component visual styles belong in `src/components/ui/` primitives or Panda config recipes.
- ❌ **Magic pixel units or raw color strings**: The compiler enforces `strictTokens: true` and `strictPropertyValues: true`. All values must map to Panda tokens.
